# 🏢 وب‌سایت رسمی صنایع درب و پنجره دوجداره تاپ‌وین (TopWin)
> **«عایق آرامش، انتخاب هوشمندانه»**

پلتفرم مدرن، تعاملی و سه‌بعدی برای تولید، معرفی و محاسبه آنلاین قیمت درب و پنجره‌های دوجداره و سه‌جداره UPVC.

---

## ✨ ویژگی‌ها و بخش‌های پیاده‌سازی شده:

1. **بخش هیرو سه‌بعدی (طراحی مطابق رفرنس ۱ ZROBIM):**
   - تایپوگرافی معماری بزرگ **TOPWIN** در پس‌زمینه.
   - بوم سه‌بعدی تعاملی Three.js / React Three Fiber با قابلیت چرخش و بازوبسته‌کردن پنجره (Sash).
   - هات‌اسپات‌های لمسی سه‌بعدی (`•`) روی شیشه، پروفیل ۵ کاناله و یراق‌آلات.
   - باکس مشخصات شیشه‌ای (Glassmorphism Spec Card) با جزئیات فنی.
   - منوی ناوبری کپسولی مینیمال (Pill Navigation).

2. **بخش مقاطع و لایه‌های عایق پروفیل (مطابق رفرنس ۳):**
   - مقاطع ۴ گانه (طرح چوب بلوطی، طوسی آنتراسیت مات، سفید صدفی کلاسیک، سه‌جداره اولترا آکوستیک).
   - اینفوگرافیک کانال‌های ۵ گانه تخلیه هوا، گالوانیزه U شکل ۱.۵mm و لاستیک EPDM دوبل.
   - آمار و شاخص‌های کلیدی: ۱۰ سال گارانتی کتبی، ۱۰۰۰+ پروژه موفق، ۲۵۰+ تنوع بازشو و رنگ، ۸۵٪ کاهش هدررفت انرژی.

3. **شخصی‌سازی و پیکربندی سه‌بعدی (Window Configurator):**
   - انتخاب مدل بازشو: دوحالته (Tilt & Turn)، کشویی مونوریل، فرانسوی دو لنگه بدون ستون، فولکس‌واگنی.
   - انتخاب رنگ پروفیل و ساختار شیشه (گاز آرگون، رفلکس سوپرسیلور، دودی سکوریت، لمینت ضدصدا).

4. **شبیه‌ساز صوتی و حرارتی تعاملی (Acoustic & Thermal Lab):**
   - مقایسه زنده پنجره قدیمی آهنی در برابر پنجره دوجداره تاپ‌وین با تغییر شدت صدا (dB) و امواج صوتی متحرک.
   - نقشه حرارتی مهار سرما و گرما.

5. **گالری پروژه‌های شاخص معماری (Projects Gallery):**
   - فیلتر پروژه‌ها (ویلاهای مدرن، پنت‌هاوس‌های لوکس، تعویض بدون تخریب).

6. **محاسبه‌گر آنلاین پیش‌فاکتور (Online Calculator):**
   - اسلایدرهای تنظیم طول و عرض، تعداد لنگه‌ها، نوع پروفیل و شیشه.
   - محاسبه متراژ مفید شیشه، طول پروفیل مصرفی و برآورد قیمت نهایی.
   - ارسال مستقیم مشخصات به واتساپ و فرم ثبت درخواست اندازه‌گیری رایگان.

7. **فوتر لوکس و استانداردهای سئو:**
   - نشان استانداردهای ملی و رال (RAL) آلمان، آدرس کارخانه و شوروم.
   - متاتگ‌های جامع سئو، نقشه سایت پویا (`sitemap.ts`)، `robots.ts` و ساختار Schema.org.

## 🚀 راهنمای نصب و اجرا:

### ۱. نصب وابستگی‌ها:
```bash
npm install
```

### ۲. اجرای سرور توسعه (Local Dev):
```bash
npm run dev
```
سپس مرورگر را باز کرده و به آدرس `http://localhost:3000` بروید.

### ۳. ساخت نسخه نهایی (Production Build):
```bash
npm run build
npm run start
```

### ۴. اجرا با داکر (Docker):
```bash
docker compose up -d --build
```
